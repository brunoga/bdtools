bdtools manual

What bdtools does and how to drive it, as pages: the same text as the documents in the repository, with the pictures.

  • Grading a film's 3D by eye

    A manual for --3d-grade: the web page and the headset that drive a 2D-to-3D conversion live, shot by shot, and the conversion that applies what you set. What the conversion does with the depth, and how it was measured, is in 2d-to-3d.md; the flags are in the command's README.

  • bdtools from the command line

    Common operations, each a complete command. Only the paths are yours. The command's README explains every flag and the choices behind the defaults; bdtools --help lists the flags.

The command's own reference, every flag and the choices behind the defaults, is bdtools' README; the design and the measurements of the 2D-to-3D conversion are in 2d-to-3d.md.

This manual is in the binary too: bdtools --manual :8080 serves it at that address, bdtools --manual DIR writes it into a directory, and the grading page links it.
