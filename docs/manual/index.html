bdtools manual

This is the manual for bdtools. It has two parts.

  • Grading a film's 3D by eye

    How to grade a 2D-to-3D conversion by eye, with the web page or a headset: from starting the server to converting the film with what you set.

  • bdtools from the command line

    The things people most often do with bdtools, each with a complete command you can copy.

    • These pages are built from the Markdown files in the repository's docs directory, so you can read the same text on GitHub. If you are after something the manual does not cover, the README of the command explains every flag and why the defaults are what they are, and 2d-to-3d.md describes how the 2D-to-3D conversion works and how it was measured.

    The manual also ships inside the bdtools binary. bdtools --manual :8080 serves it at that address, bdtools --manual DIR writes the files into a directory, and the grading page has a link to it.
